# Mossworks Labs

This repository holds the [community defaults](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for every public repository in the [Mossworks Labs](https://github.com/Mossworks-Labs) organization.

## What lives here

- [`profile/README.md`](profile/README.md) — the org's public landing page.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md) — community-health files inherited by every repo that doesn't define its own.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) and [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — default issue and PR forms.
- [`workflow-templates/`](workflow-templates) — starter workflows surfaced under **Actions → New workflow → Mossworks Labs** in any org repo.

## What's elsewhere

Reusable GitHub Actions workflows, governance JSON (rulesets, repo-settings), and admin scripts live in [`Mossworks-Labs/actions`](https://github.com/Mossworks-Labs/actions). That's where to look for `pr.yml`, `docker-build.yml`, `helm-deploy.yml`, `apply-rulesets.yml`, etc.
